#  MERN Task & Project Management System

A full-stack responsive web application built with the MERN stack for managing personal tasks and project workflows effectively.

---

##  Live Demo & Deployment
- https://mern-task-manager-ui.onrender.com

---

##  Features
*  **User Authentication:** Secure Signup & Login using JWT (JSON Web Tokens).
*  **Task Management:** Full CRUD operations (Create, Read, Update, Delete tasks).
*  **Interactive Dashboard:** Filter tasks by status (Pending, In Progress, Completed).
*  **Responsive UI:** Modern design crafted with React & Tailwind CSS.
*  **Cloud Database:** Hosted on MongoDB Atlas.

---

##  Tech Stack
- **Frontend:** React.js, Tailwind CSS, Axios, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose ODM)
- **Deployment:** Render (Static Site & Web Service)
